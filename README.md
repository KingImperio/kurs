# Kurs

Minimal vanilla JS currency converter with live exchange rates for 12 currencies.

## What it does

Kurs converts between major world currencies in real time using a free public FX API. It is built for people who need a fast, no-friction conversion tool without ads, charts, or tracking. Type in either field and the other updates instantly.

## Tech

- HTML / CSS / JavaScript (Vanilla)
- ExchangeRate-API (free tier, no key required) for live rates
- Satoshi from Fontshare

## Run locally

Download or clone the repo. Open `index.html` in a browser. No build step required.
